# Client creature/prop controller anim-int maps - extracted from Romestead.dll client
# controllers (EntitySpacAnimationStateMachine State lists + Transition predicates on
# `State == N` + OnServerSetState / ReceiveEntityAnimationMessage switches).
#
# Used by: AI preset anim-int params + forge_creature_anim anim-map. Two channels:
#   * state int - persistent controller state the server replicates (OnServerSetState;
#                 the client plays the anim whose transition checks `State == N`).
#   * anim byte - one-shot animation message (ReceiveEntityAnimationMessage switch).
# A controller may use either or both. `states:` is the full ordered State[] list the
# rig's state machine was built with (= valid animation names in that spac).
#
# KNOWN-PARTIAL: only mappings readable in the decompile are listed. Controllers whose
# handlers set fields instead of calling SetState directly (e.g. cyclops, old wolf) are
# marked. Movement states (idle/walk/run) often also auto-switch on velocity client-side.
