# Biome ids and biome categories — two DIFFERENT namespaces, don't mix them:
#
#   * Prefixed BIOME ids ("biome:plains") = actual map terrain biomes (Shared.BiomeIds
#     consts + BiomeData registrations in CandideServer). Use these where a field wants
#     a biome id — e.g. a forge map's biome.
#   * Bare CATEGORY names ("plains") = BiomeCategoryDataBase (SetupBiomeCategories, 9
#     entries). Crops (`biomes`), shops (`BiomeCategory`), and work recipes
# (note: the game's internal work-recipe model can biome-gate recipes; the pack format does not expose this yet)
#
# Each biome maps to one category (shown after the arrow, from the vanilla BiomeData
# list in CandideServer.decompiled.cs). Both lists are COMPLETE for vanilla.
#
